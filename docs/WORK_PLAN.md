# Clubena 作業工程表 v3

**単位**：1ブロック = 1時間（中断可能な粒度で切ってある）
**総量**：104時間（済み11時間・任意3時間を含む）→ **残り約93時間**
**根拠**：`docs/SPEC.md` v2.0
**構成**：Cloudflare Workers の静的配信（画面）／Supabase 東京（DB・認証・Edge Functions）／GitHub（コード）／LINEミニアプリ（Clubena共通の1つ）

**v2（115h）からの主な変更**（2026-10-14）
- LINEは Clubena 共通のミニアプリ1つに。クラブごとのLINE作業（プロバイダー・公式アカウント・Messaging API）がなくなった
- 工程1は「最初に1回だけ」の3時間に。工程5（リッチメニュー）と、トークでの欠席受付bot（旧7-4）を削除
- メールでのログイン（旧3-9）を削除。ログインはLINEのみ
- 通知（工程11）は LINE へのプッシュをやめ、アプリ内の表示に
- 追加：Excelの取り込み・書き出し、機能の段階的な解放、導入代行（工程13）、保護者のホーム画面と下のタブ
- 工程2（データベース）は完了済み

## v1では作らないもの

| 外すもの | 理由 |
|---|---|
| LINEへのプッシュ通知 | 公式アカウントを持たない。必要になったら Clubena の公式アカウントを1つだけ |
| メール・SMSでのログイン | ログインはLINEに一本化 |
| クラブごとのLINE設定（プロバイダー・公式アカウント・リッチメニューの出し分け） | 運営とクラブの負担が大きい |
| アプリ内チャット | LINEトークで足りる |
| 決済・口座振替 | 非提供機能。将来はStripe Connect Standard |
| 住所等の保持・ファイルアップロード | 紙でクラブが保管（仕様書 原則D） |
| 級の専用機能（スタンプカード等） | タグ＋変更履歴で代替 |
| 月謝の出席回数ベース精算 | 事後精算はトラブルが多い |
| 指導案エディタ・試合管理 | 別プロダクト規模 |
| 送迎・入退室打刻 | 需要未確認／ハードウェア依存 |
| ノーコードツールへの移行 | 人数課金・LINEログイン非対応・データが米国（`DECISIONS.md` 2026-10-14） |

# 仕様書 v1.7 と指示書（プロジェクト指示）の差分、新ホーム画面の実装範囲（2026-10-11）

基準は「NOBIT! 基本仕様書 v1.7」。指示書と食い違う場合は仕様書を優先する（指示書の冒頭の取り決め）。

## 1. 指示書にない・古い箇所（仕様書が新しい）

| 項目 | 指示書 | 仕様書 v1.7 |
|---|---|---|
| ホームの構成 | 最初の画面は連続日数・今日のタスク・教科ボタンの3つ。ノビットの一文・応援などは下 | 記録の状況で5つの状態（はじめて・今日まだ・記録中・タスク完了・再開）に切り替える。ノビットの一文は最初の画面に状態別で置く |
| 記録したあと | 記述なし | 「今日の記録」（件数と、時刻・名前・種類の一覧、新しい順）を主役にする |
| はじめての日 | 記述なし | 「今日が1日目」（0日とは出さない） |
| 画面08 | 独立した画面（08 記録が途切れたあと） | ホームの「再開」の状態。下部タブを残し、閉じる操作をなくす |
| 再開の中身 | ノビット・記録の帯・最長記録とバッジ数・短いタスク | ノビット（手をふる）と「おかえり。また今日から。」、最長記録とこれまでの学習日数、「チケットで守る」（使えるとき）、教科ボタン、短い順のタスク最大3件。帯・バッジ数・空いた日数は出さない |
| 今日のガチャ | 記述なし | 記録中・タスク完了の状態で、まだ引いていなければ1行 |
| 応援 | ホームに一文 | 新しく届いた日だけ、ノビットの一文の下に1行。常時は下のスクロール部分 |
| 下のスクロール部分 | 記録の帯・コイン・デイリークエスト・次のバッジ | 次の称号・バッジまでの残り（数字と細い線）、記録の帯（直近14日・曜日つき・「記録がない日も責めない。続けたぶんがここに残る。」）、デイリークエスト、コイン、15分集中の入口、クラブ管理者の応援 |
| ノビットの画像 | 完了の瞬間・ガチャ・再開・15分集中 | ホームで画像を出すのは再開の状態だけ（タスク完了の状態には出さない） |
| 種類の表示 | 記述なし | タスク・教科・タイマーは灰色の文字。パープルは称号・レア・休息日だけ |
| 面の色 | 配色の定義のみ | 1画面に1〜2か所（連続日数の面と主なボタン）、カードの影は使わない |
| 画面の記号 | アイコンで飾らない | アプリ内にロゴとメニューの記号を置かない |
| 今月の学習日数・最長記録 | 記述なし | ホームから外し、ふりかえり（06）とコレクション（04）に置く |

## 2. 指示書の更新案（差し替え用）

「## 画面」の生徒の箇条を次のように置き換える。

- 生徒（幅390px、下部タブ：ホーム／ふりかえり／コレクション／ミッション）：01 ホーム・今日のクエスト、02 タスク完了の瞬間、03 15分集中モード（通常タイマーも同じ画面）、04 コレクション、05 無料ガチャ（結果）、06 ふりかえり、07 ミッション。08（記録が途切れたあと）はホームの「再開」の状態として出す
- ［仮］v1.7 のホーム：記録の状況で5状態（はじめて・今日まだ・記録中・タスク完了・再開）に切り替える。最初の画面は「今やること」だけ（連続日数、ノビットの一文、教科ボタン、今日のタスク。記録したあとは「今日の記録」の一覧を主役）。下のスクロール部分は、次の称号・バッジまでの残り、記録の帯（14日・曜日つき）、デイリークエスト、コイン、15分集中の入口、応援
- ホームで画像のノビットを出すのは再開の状態だけ。完了の瞬間は 02 で出す

「## デザイン原則」に次を足す。

- 種類の表示（タスク・教科・タイマー）は灰色の文字。パープルは称号・レア・休息日だけ。面の色は1画面に1〜2か所、カードの影は使わない。アプリ内にロゴとメニューの記号を置かない

## 3. 新ホームの実装（このバッチ）

| 項目 | 仕様書 | 状況 |
|---|---|---|
| 5つの状態の切り替え | ホーム（01）の見せ方 | ◎ `homeStateOf`（今日の記録の数・これまでの学習日数・配信タスクの完了・再開で判定） |
| はじめて | 「今日が1日目」、一文、教科ボタン、タスク | ◎ |
| 今日まだ | 連続日数と「あと◯日で…」、一文、教科、タスク（完了・タイマー） | ◎（下の［仮］参照） |
| 記録中 | 連続日数、今日の記録、ガチャ1行、残りのタスク、教科 | ◎ タスクから始めたタイマーは別の行にしない（記録の数え方と同じ） |
| タスク完了 | 「今日のタスクは完了」、今日の記録、ガチャ1行、控えめな入口 | ◎ |
| 再開 | ノビット（手をふる）、最長記録・これまでの学習日数、チケットで守る、教科、短いタスク最大3件 | ◎ 別画面（Resume）は廃止。タブを残し、閉じる操作なし。見たことは最初の表示で記録 |
| 一文 | はじめて「最初の1件を残そう。」ほか | ◎ |
| 応援 | 新着の日だけ一文の下、常時は最下部 | ◎ |
| 記録の帯 | 14日・曜日つき・注記 | ◎ |
| ロゴ | 置かない | ◎ 「NOBIT!」の見出しを外した |
| 次の称号・バッジまでの残り | 数字と細い線 | ［仮］称号・バッジの条件の仕組みがないため、連続日数の節目（7・30・100・365日）で代用 |
| 状態のバッジ（すべて完了／一部完了／未着手） | 本文に指定なし | 今日のタスクの見出し横から外した（完了は時刻、未完了はボタンで読める） |

v1.7 は、v1.6 に対する［仮］の見直しです。仕様書10章の確定順（①〜⑤）に沿って、実装との差分を示します。

## ① 記録の整理と報酬の3ルール

| 項目 | v1.7 | 状況 |
|---|---|---|
| 記録の入口 | 画面は「タスク」と「教科」の2列。どの入口も同じ学習の記録 | ◎ |
| タスクの行 | 「完了」と「タイマー」。完了は時刻を表示 | ◎（タイマーで始めて終えると、そのタスクも完了） |
| 教科ボタン | 1タップで記録。そのあと「内容を足す」「この教科でタイマー」 | ◎ |
| 同じ教科は1日1回 | 2回目は記録した時刻を表示 | ◎（ボタンに時刻を表示。DBでも1件に抑える） |
| 内容は事後にも書ける | 内容に報酬なし | ◎ `set_study_content` |
| 自由登録 | 「教科の記録＋内容」に一本化。自分のタスクを作る画面は持たない | ◎（ホームから外した。完了時のタスクのコインは付けない） |
| 学習した日 | 入口を問わず1日1コイン | ◎ |
| 配信タスク | 運営設定（標準10コイン） | ○ |
| 15分集中 | 達成5コイン・1日1回 | ○ |
| 内容の報酬 | やめる（v1.6 の内容つき3コインを廃止） | ◎ |

| ホームの下 | 記録の帯・ノビットの一文・応援（1行）・コイン・デイリークエスト・次のバッジ・15分集中の入口 | 一部◎（帯・ノビット・応援・コイン・15分集中）。デイリークエストと次のバッジは ✕ |

| 完了の瞬間（02） | その日の最初の記録・連続記録の節目・バッジ獲得のときだけ全面表示。2件目以降は行に時刻だけ | ◎（バッジ獲得は、バッジの仕組みができたあと） |
| ガチャへの導線 | 最初の記録のシートに「今日のガチャを引く」 | ◎ |
| 06 カレンダーの色 | 記録の帯と同じ数え方 | ○（日別の記録の数を使用） |
